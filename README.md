# PokemonGO App

Welcome to **MyPlaces**, your ultimate Pokémon-inspired adventure app! Explore, collect, and battle your way through your favorite spots in the city while tracking your personal progress.

---

## Features

### 🧑 User Profiles
- View your own profile or visit friends’ profiles
- Displays **avatars**, level, XP, wins, and losses
- Smooth profile UI with progress bars and stats

### 🐾 Pokémon Collection
- Catch, collect, and manage your Pokémon
- See your Pokémon’s **level, HP, and attack**
- Disown or swap Pokémon easily

### ⚔️ Battles
- Challenge wild Pokémon in locations (`MyPlace`)
- Real-time battle logs with **highlighted damage, XP, and results**
- XP and level-up system integrated
- Capture defeated Pokémon if eligible

### 🗺️ Map Integration
- Explore your city or local areas on the map
- Visit locations to find Pokémon
- Real-time updates on nearby places and Pokémon

### 🔧 UI & Experience
- Filters and sorting for Pokémon list (Level, HP, Name)
- Alive/dead toggle for Pokémon
- Smooth avatars selection (camera, gallery, default icons)
- Bottom navigation for quick access to Home, List, Map, Leaderboard, Profile

### 🛠️ Tech Stack
- **Kotlin** + **Android Jetpack**
- **Firebase**: Firestore, Authentication, Storage
- **RecyclerView** & **Adapters** for dynamic lists
- **ProgressBars** & **custom views** for stats
- Clean MVVM architecture with **ViewModels**

## Installation
1. Download the latest release APK from the [Releases page](https://github.com/<your-username>/<repo>/releases).
2. Transfer the APK to your Android device.
3. Open it to install (you might need to allow installation from unknown sources).
4. If you already have a previous version installed its important to remove it from your device


## Alternatevly
1. Clone the repo:
   ```bash
   git clone https://github.com/ivkoneli/MyPlaces
    ```
2. Open in Android Studio
3. Build & run on your device/emulator
